# 重点品线运营工作台

单文件页面 `index.html`，覆盖美国站重点品线：冲击扳手、黄油枪（拆为两用款、三速款、直柄款）、充气泵、工作灯（灯具）、钉枪（木工钉枪）、油泵（锂电油泵）、逆变器（电源逆变器）。

1. 整体看板：分品线销售额、环比、同比（按日均）、销量、订单、件均价、库存可售天数、预警数；2026 vs 2025 月度对比图
2. 核心 ASIN 数据：每品线近 90 天销售额前 3 的 ASIN，按月份筛选
3. 广告费用：按 SPU 汇总各品线广告花费结构、ACOS、TACOS、广告订单占比、毛利率
4. 库存与周转：库存快照、可售天数、预计售罄日、近 6 个月月末库存与周转
5. 预警处理：按规则筛出问题 ASIN，运营填写处理状态和说明（保存在工作台共享存储）
6. 竞对与目标排名：8 周周均小类排名、周日销、目标（编辑者在页面上设定）、各品线对标竞品
7. 监控规则：阈值和口径，编辑者可在页面上修改

## 数据

- 销量、订单、销售额、库存：ASIN 日销量导出，2025-01-01 至 2026-10-22，美国站（10-23 当天数据不完整，已排除）。
- 小类排名历史、当前售价、FBA 单件费、评分：卖家精灵（keepa_info / competitor_lookup），2026-10-23。
- 竞品：卖家精灵同小类近 30 天销量靠前的兼容电池类产品，已排除我司品牌和原厂品牌。
- 毛利、广告（SP/SB/SBV/SD）、退款、Sessions、在途与补货库存：领星“产品表现-ASIN”日报，2026-09-01 至 2026-10-23（10-24 不完整已排除），七个品线全部覆盖；毛利取订单毛利润。
- 库龄：尚未导入。
- 页面中的 `const DATA = {...}` 是全部数据。
