# 重点品线运营工作台

单文件页面 `index.html`，覆盖冲击扳手、黄油枪、充气泵、工作灯四个重点品线：

1. 整体看板：分品线销售额、毛利、广告费、TACOS、库存货值、预警数
2. 核心 ASIN 费用明细：按月份筛选的收入、费用和毛利
3. 广告费用：按 SPU 汇总 SP 自动 / 关键词 / ASIN 定投、SB、SBV、SD
4. 库存与费用：库存结构、可售天数、库龄、仓储费
5. 预警处理：按规则自动筛出问题 ASIN，运营填写处理状态和说明（保存在工作台共享存储）
6. 竞对与目标排名：目标排名、目标日销、每周完成情况和对标竞品
7. 监控规则：阈值和口径，编辑者可在页面上修改

## 数据

- 我司 ASIN（`B0SMPL` 开头）和经营数字为示例数据。
- 竞品数据来自卖家精灵 2026-10-22 抓取的美国站近 30 天数据。
- 页面中的 `const DATA = {...}` 是全部数据，替换成真实数据后结构保持不变即可。
