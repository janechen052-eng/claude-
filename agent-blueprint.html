AI Agent 规划 · 业务图

把高手的判断，变成每个人都能用的 Agent

按角色拆分，先把部门 leader 看数据、做判断的路径沉淀成 Skill，训练出 6–7 个基础角色 Agent；再搭公司工作台和知识库，让“看板 → 判断 → 行动 → 复盘”形成闭环，越用越准。

阶段一：角色 Agent 阶段二：公司工作台 阶段三：公司知识库 判断闭环 板块内驻场 Agent

Agent 权责分级

对应草图中的“底层 Agent 权责”。新 Agent 从 L1 起步，准确率达标后逐级放权。

L1只看：汇总数据、出日报周报，不给结论
L2建议：发现异常并给出判断和建议，人来决定
L3审批后执行：生成操作方案，负责人点确认后执行
L4授权自动：限额内自动执行（如小幅调竞价），事后通知

三阶段落地计划

时间是建议值，按 6 个月规划。阶段二和阶段三可以在阶段一跑通 2–3 个角色后提前启动。

第 1–2 月

阶段一 · 角色 Agent

  • 确定 6–7 个角色和对应 leader
  • 收集各部门现有看板，整理成看板 V1
  • leader 结合真实案例访谈，每个角色先产出 15–20 张判断卡
  • 用历史案例回测，迭代到 V2、V3
  • 定好每个 Agent 的权责级别
验收：回测时 Agent 判断与 leader 一致率 ≥ 80%
第 3–4 月

阶段二 · 公司工作台

  • 统一指标字典和数据口径
  • 搭建公司级、品类级、部门、平台/团队四层板块
  • 角色 Agent 入驻对应板块，配置异常预警
  • 按角色开放查看和操作权限
验收：各部门日常看数据只用一个入口；每日预警被处理率 ≥ 90%
第 4–6 月

阶段三 · 知识库与闭环

  • 收集部门 SOP、复盘、产品与供应商资料
  • 判断卡入库，建立案例库
  • 接入外部信息爬取：平台政策、竞品、关键词趋势
  • 每次行动的结果自动回写，季度做一次 Skill 升版
验收：Agent 建议采纳率、判断准确率、节省工时三项指标按月追踪

风险与对策

高手的经验说不清楚不要让 leader 空讲规则，而是拿 3–5 个真实案例复盘：“当时看到了什么，为什么这么判断”，再从中提炼判断卡。
各部门数据口径不一致阶段二开始前先出指标字典，同一指标只有一个定义和一个数据源。
Agent 越权或误判造成损失按 L1–L4 逐级放权，L4 设金额和幅度上限，所有自动操作留日志可回滚。
判断逻辑过时每张判断卡有负责人和版本号，结果复盘发现偏差就触发升版，季度统一评审。
员工不用先从 leader 最头疼的重复判断切入（如补货、广告调价），让一线先感受到省时间。
